Hotel Booking & Revenue Analysis

Project Overview

This is an end-to-end Data Analytics project based on the Hospitality Industry.

The objective is to analyse hotel booking patterns, revenue performance, customer preferences and cancellation trends to generate meaningful business insights.

Business Objectives

Analyse hotel booking trends.

Identify the highest revenue-generating hotels.

Understand booking cancellation patterns.

Analyse customer preferences for room types.

Evaluate booking channel performance.

Monitor customer satisfaction.
